# Parcel Shift

RBE104TC 仓库配送游戏，提供终端版和 SDL2 像素窗口版。机器人拾取包裹并送回配送点，同时避开叉车。窗口版从开始菜单选择关卡、追击机器人数量和地图档位，送达全部包裹后播放胜利庆祝动画。

终端版用于满足课程提交要求，SDL 版继续保留。后续开发要求两端保持相同的游戏功能；输入方式和显示形式可以不同。两端共用 `game.c` 的状态、规则、回合处理、暂停、重开和胜负判断；终端与 SDL 分别负责输入和显示。

## 编译与运行

以下命令从仓库根目录（包含本 README 的目录）在 Windows PowerShell 中执行，需要 GCC 在 `PATH` 中。

```powershell
.\scripts\build_basic.bat
.\build\windows\terminal.exe
```

默认构建与 `basic` 参数相同：编译终端版、预览和测试程序，运行测试，并生成 `build/windows/preview.ppm`、`delivered.ppm`。脚本结束时按任意键返回。

终端版先输入叉车数（1–5），再输入关卡号（1–99999，也是唯一 seed，直接回车默认 1）。每次输入一个命令后按回车：W/A/S/D 移动，P 暂停/继续，R 重开当前关卡，Q 退出；大小写均可。胜负后可用 R 重开或 Q 退出，获胜后 N 进入下一关。

窗口版：

```powershell
.\scripts\build_basic.bat gui
.\build\windows\parcel_shift.exe
```

打开后先进入开始菜单。关卡号（1–99999）是唯一 seed；追击机器人可选 2–5 辆；地图档位 2–4 与关卡区间联动。难度预设 EASY / NORMAL / HARD 是现有参数的快捷组合：2 档地图加 2 辆、3 档加 3 辆、4 档加 5 辆，不改变追踪范围、速度或碰撞规则。

- 点击中间数字框直接输入关卡号（第一次输入替换旧值），+/- 逐关调整；Tab / Shift+Tab 切换控件，Enter 确认。
- START DELIVERY 按菜单配置开始新局，会替换当前进度；RESUME 继续当前游戏，不应用尚未开始的新配置；EXIT 退出。菜单期间游戏不推进。
- 开始前在后台验证可通关路线并显示 PREPARING；失败时提示换一个关卡。选择 5 辆叉车时会额外验证第 5 种配置，必要时改用后续候选地图。
- 命令行参数可预填关卡号和机器人数量（1–5），仍需在菜单确认。关闭游戏后再重新编译。

`scripts\build_basic.bat window-test` 使用 SDL dummy 驱动和事件队列检查菜单预设、种子编辑、必填与范围校验、5 辆叉车通关路线、进入游戏、暂停、重开、返回菜单、继续、全屏切换、胜利庆祝与卡片点击、窗口尺寸变化和退出；不验证物理键盘、桌面焦点、输入法或实际显示与声音。

地图格子固定为 44×44，角色和地图道具图标固定为 36×36 逻辑像素。菜单画布固定 1280×720；游戏画布从 1280×800 随地图扩展，最大为 1808×1152；切换地图尺寸时自动调整窗口。超过屏幕工作区时等比缩小以显示完整界面，手动缩放窗口也保持宽高比。窗口版声明 per-monitor DPI 感知，高缩放比例下窗口按像素大小显示，不再被系统放大到工作区之外。

| 窗口操作 | 按键 |
| --- | --- |
| 移动一格 | WASD 或方向键，长按不连发 |
| 暂停 / 继续 | 空格 |
| 重开当前关卡 | R |
| 获胜后进入下一关 | N（99999 关禁用） |
| 返回开始菜单 | M 或 Esc |
| 继续当前游戏 | 菜单中 RESUME 或 Esc |
| 全屏 / 窗口切换 | F11 |
| 退出 | Q、菜单 EXIT 或关闭窗口 |

获胜后显示庆祝动画，卡片上的 NEXT DELIVERY / PLAY AGAIN / MAIN MENU 也可用鼠标点击。动画只使用经过的毫秒数绘制，不推进回合、不改变成绩；从菜单继续已获胜关卡会重新播放动画，但不会重复播放胜利音效。

GUI 构建需要与 GCC 架构匹配的 MinGW SDL2 开发库。已验证版本为 SDL2 2.32.10。将开发包中匹配架构目录的内容放入以下位置，并保留开发包的 `LICENSE.txt`：

```text
deps/SDL2/include/SDL2/SDL.h
deps/SDL2/lib/
deps/SDL2/bin/SDL2.dll
deps/SDL2/LICENSE.txt
```

脚本默认使用仓库内的 `deps/SDL2/`。也可用 `SDL2_ROOT` 指定其他目录；相对路径以仓库根目录为基准，例如：

```powershell
$env:SDL2_ROOT = '.\deps\SDL2'
.\scripts\build_basic.bat gui
```

`deps/` 不纳入 Git，接收方需自行安装 GCC 和 SDL2 开发库。脚本将 DLL 复制到 EXE 旁，并从 SDL2 目录或其上级目录复制 `LICENSE.txt` 为 `SDL2-LICENSE.txt`。GUI 构建还需要 MinGW 的 `windres`，用于嵌入 `assets/parcel_shift.ico`。脚本将六个 WAV 和 `assets/menu_background.bmp` 复制到 EXE 旁的 `assets/`。分发窗口版时一起保留 `parcel_shift.exe`、`SDL2.dll`、`SDL2-LICENSE.txt` 和 `assets/`。窗口版不依赖 SDL_image、SDL_ttf 或外部字体、图片；菜单背景由程序读取 BMP 后整体绘制。

仓库根目录保留了可直接运行的窗口版副本 `parcel_shift.exe`，旁边放有 `SDL2.dll`、`SDL2-LICENSE.txt`，并直接使用仓库的 `assets/`。该副本不随后续构建自动更新；重新编译后如需更新交付文件，手动复制 `build/windows/parcel_shift.exe` 到仓库根目录。

SDL 版自动循环 124 BPM 背景音乐；有效移动、拾取、碰撞、配送和通关播放对应音效，最后一次配送只播放胜利旋律。暂停时背景音乐继续，当前音效清空；重开和按 N 也清空音效。返回菜单时背景音乐继续，继续游戏不清空已有局面。音量通过 Windows 音量混合器调整。音频从 EXE 旁的 `assets/` 加载，设备或文件不可用时继续游戏。终端版不链接 SDL 或音频模块。

离线音频测试需要 SDL2 开发库，不打开窗口或声音设备：

```powershell
.\scripts\build_basic.bat audio
```

`tools/make_music.py` 和 `tools/make_sfx.py` 可用 Python 标准库重新生成 WAV；正常构建直接使用已有资源，不运行生成脚本。`assets/menu_background.png` 是菜单背景源图，运行时读取 `menu_background.bmp`，两张图不参与游戏规则。同学交付包附带这些合成脚本；其说明标注图标由 AI 辅助生成，贡献与协助声明按实际情况填写。

## 游戏规则

- 有效移动后，每辆叉车行动一次；撞墙和无效命令不消耗回合。
- 每次携带一个包裹，送回配送点得 100 分，全部送达后获胜。
- 包裹数随地图增加：9×15 为 3 个；9×19、11×23 为 4 个；13×27、17×31 为 5 个。
- 初始三条命，碰撞每回合最多扣一命。机器人和叉车回到各自起点，携带包裹落在碰撞位置，重生后需重新拾取；落点已有包裹时叠放，每次只拿一个。
- 每局有 50% 概率在第 5–20 个有效移动回合结束后掉落一个回血道具，最多一个，不补刷。落点为空地，避开机器人、叉车、包裹和配送点；无空地时延后尝试。终端显示 `+`，SDL 显示爱心。无碰撞时走上去回复一命，上限三命，满血时保留。重开复现掉落设置。
- `HEALTH` 显示本关回血状态：`NONE THIS LEVEL` 不掉落，`WAITING` 待掉落，`ON MAP` 已出现，`COLLECTED` 已拾取。出现时另有 `Health dropped!` 提示。第 4 关沿出生点右侧安全区用 D/A 来回移动，第 11 个有效回合会出现，可用来检查掉落显示。
- 出生点和配送点的曼哈顿距离一格以内为安全区，叉车不能进入；SDL 用绿色地格标出。安全区不包含包裹周围。
- 叉车巡逻时直行，受阻才转向；可走路径距离不超过四格时发现玩家，最多追踪六个有效移动回合，再冷却四回合。玩家进入安全区立即停止追踪；无合法方向时等待。
- SDL 追踪中的叉车显示红色底框和感叹号；终端以 `!` 代替 `F`。
- SDL 碰撞后在屏幕中央显示扣命和重生提示，停留 1.5 秒，期间忽略移动、暂停和换关输入，仍可退出、重开或返回菜单。终端显示碰撞提示框，等待下一条输入。
- 获胜后显示庆祝动画：机器人抱箱跳跃，烟花循环播放。动画不推进回合、不改变成绩；N/R/M 键与卡片按钮可用，99999 关不进入下一关。
- 同版本下，相同关卡号、叉车数量和操作序列可复现；地图和叉车使用固定 32 位随机算法。
- 地图先通过连通性检查，再验证获胜路线。选择 1–4 辆叉车时仍按原四种配置验收，保证 1–4 的旧地图不变；选择 5 辆时额外验收第 5 种配置，必要时换用后续候选，因此 5 辆的地图可能与 1–4 不同，但相同配置与关卡号仍可复现。超过生成或搜索上限会提示失败，不放行未验证地图。

关卡 1–999 为 9×15，1000–9999 为 9×19，10000–29999 为 11×23，30000–59999 为 13×27，60000–99999 为 17×31。内部重试保持尺寸和关卡号不变。生成、重试和检查约定见 [关卡实现](docs/LEVELS.md)。

## 文件入口

| 路径 | 用途 |
| --- | --- |
| `src/game.c`、`src/game.h` | 终端、窗口、预览和测试共用的地图、状态、规则与游戏操作 |
| `src/level.c`、`src/level.h` | 确定性地图生成、尺寸分段与 BFS 合法检查 |
| `src/solver.c` | 调用共享核心搜索获胜路线 |
| `src/scene.c`、`src/scene.h` | 随地图扩展的像素缓冲区、固定尺寸图标、字体、HUD、菜单绘制入口和胜利庆祝动画 |
| `src/menu.c`、`src/menu.h` | 菜单背景加载、按钮命中、难度预设、关卡号编辑与地图档位 |
| `src/window.c` | SDL2 窗口、菜单/游戏流程、键盘鼠标事件、缩放、全屏与音效触发 |
| `src/audio.c`、`src/audio.h` | SDL 音频设备、循环背景音乐与单路事件音效混音 |
| `assets/`、`game_icon.rc` | 六个 WAV、菜单背景 BMP/PNG、图标及 Windows 图标资源声明 |
| `tests/test_audio.c` | WAV 格式、音效输出、循环边界与混音检查 |
| `tests/test_menu.c` | 菜单点击、预设、种子编辑、范围校验、RESUME 与五叉车路线回放检查 |
| `tests/test_celebration.c` | 真实获胜路线下的庆祝帧变化、状态不变、重开和最大地图检查 |
| `tests/test_window_flow.c` | dummy 驱动下正式事件循环的菜单、继续、暂停、重开、全屏与退出检查 |
| `tests/test_victory_flow.c` | dummy 驱动下正式事件循环的获胜、庆祝、点击重玩、再次获胜与下一关检查 |
| `src/terminal.c` | 终端输入和文本显示入口，调用共享游戏核心 |
| `tests/test_terminal.py` | 终端命令、暂停、重开、胜负后操作、五叉车通关和输入校验集成测试 |
| `tests/test_game.c` | 规则断言、五叉车验收、绘制调用与 PPM 写入检查 |
| `tools/preview.c` | 不依赖 SDL 的初始画面导出入口 |
| `scripts/build_basic.bat` | Windows 构建入口 |
| [维护与交接](docs/TEAM_HANDOFF.md) | 修改位置、同步要求和提交待办 |
| [测试记录](docs/TEST_RESULTS.md) | 复现命令、结果与未验证项 |
| [report 编程素材](docs/REPORT_MATERIALS_ZH.md) | 供组员筛选的实现说明、问题修复与测试案例 |

不要把全部 `*.c` 一起编译：窗口、终端、预览和测试分别定义 `main()`。修改规则时只改 `game.c`；两端通过 `processCommand()` 提交游戏操作，通过 `getGameStatus()` 读取胜负状态。退出由各前端处理。

终端集成测试需额外安装 Python 3；基础构建不依赖 Python：

```powershell
python tests/test_terminal.py
```

构建输出统一放在 `build/windows/`。上方 PNG 是保存的预览，构建不会自动更新它。

## 课程提交限制

仓库内的[作业 PDF](docs/assignment.pdf)要求 standard C、terminal-based 游戏。提交保留不依赖 SDL 的终端版；如需附交 SDL 窗口版，按教师要求处理。终端版需要编译 `src/level.c`、`src/solver.c`、`src/game.c`、`src/terminal.c`，并提供相应头文件；不能单独编译 `terminal.c`。显示层中的位运算、像素缓冲区和 SDL 事件需要成员自行理解。

报告最多 1500 词，需附源码、构建运行说明、至少三个可复现场景和真实贡献声明。PDF 中截止日期为待定，实际日期以课程通知为准。本原型使用了 AI 辅助，协助披露按课程政策填写。
